## 📌 About The Project

EcoMind AI is a desktop application designed to help households and communities
record, analyze, and manage their daily waste.

The system tracks waste categories, recycling activity, waste statistics,
high-waste categories, and sustainability recommendations.

---

## 🎯 Objectives

- Record daily household waste
- Track recycling activity
- Analyze waste patterns
- Identify high-waste categories
- Generate sustainability recommendations
- Provide useful waste reports

## ✨ Features

### 📊 Waste Tracking

- Add waste records
- Update records
- Delete records
- Search records
- Track waste by category
- Record recycled quantity

### 📈 Statistics

- Total waste
- Category-wise percentage
- Recycling rate
- Highest-waste category
- Waste analysis
- Visual charts

### ♻️ Recycling

The system tracks recycled materials and calculates the overall recycling
performance of the recorded waste.

### 💡 Sustainability Recommendations

The application analyzes recorded waste information and provides
actionable recommendations for improving waste-management practices.

### 📋 Reports

Generate a summary for a selected period containing important waste and
recycling information.

## 🏗️ OOP Implementation

The project demonstrates Python fundamentals and Object-Oriented Programming.

### `User / Household`

Represents the household or user using the system.

### `WasteRecord`

Represents an individual waste record containing information such as:

- Date
- Category
- Quantity
- Recycling status
- Description

Additional classes may be used for database management, analysis,
recommendations, and GUI components.
